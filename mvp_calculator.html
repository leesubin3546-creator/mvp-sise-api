🍁 메이플 MVP작(엠작) 비용 계산기

목표 등급까지 남은 실적을 메소마켓식 vs 경매장식으로 비교. 어떤 방법이 돈이 덜 드는지 알려줘.

1 목표 등급 & 현재 사용 캐시

※ 마일리지·할인으로 깎인 금액은 실적에 안 잡혀. 실제로 소모한 넥슨캐시만 등급에 반영돼.

2 공통 시세 입력

예: 문상·현대카드 10% 할인 → 10
직접 입력(로아땡·아이템매니아 등에서 확인)

3 방법 선택

메소마켓식
경매장식
📌 아래 “실적 1만원당 실부담”은 등급 실적을 1만원어치 쌓을 때 환금까지 끝내고 실제로 빠져나가는 순수 손해액이야. 낮을수록 좋고 음수(초록)면 오히려 이득. 옆의 %는 손해율(충전액 대비).
게임 내 메소마켓 “억당 시세” 확인. (메포 1개 = 1캐시 = 실적 1원)
이미 가진 마일리지
넥슨캐시 결제액의 5% 적립(기본). 엠작 중 자동 적립분 반영
아이템캐시가격마일리지%
(실적↓)		판매가
(억메소)		시세 본전가
(억메소)		1만원당
손해
여러 아이템을 넣으면 자동으로 최적 조합을 짜줘: 마일리지(보유+엠작적립)는 “마일 할인 시 손해율 최저” 아이템에 몰고, 나머지 실적은 “정가 손해율 최저” 아이템으로 채워.
마일리지%: 마일로 깎이는 비율(플래티넘 카르마의 가위 등 30). ⚠ 할인분은 넥슨캐시로 안 나가 실적도 안 쌓임. 본전가 = 손해 0 되는 최소 판매가(마일 적용 기준).
🔍 시세 버튼: 옥션 구매 탭 1개를 계속 재사용하면서 개당 실시간 최저가(구매 최저가)를 판매가 칸에 자동으로 채워줘. (최근 거래 시세는 안 봄 — 최저가만으로 충분해서 뺐고, 탭도 하나만 써서 넥슨이 "다른 환경에서 접속 감지"로 세션을 끊어버리는 문제도 같이 해결됨). 자동 반영에는 유저스크립트 설치가 필요해(Tampermonkey 등). 옥션은 넥슨 OTP 로그인 필요 — 이 스크립트는 로그인을 대신하지 않고, 사용자가 이미 로그인한 화면의 가격만 읽어서 보내. 열린 옥션 탭에서 로그인이 안 돼 있으면 검색 결과 자체가 안 떠서 판매가가 안 채워지니, 먼저 그 탭에서 로그인해줘. 🗙 옥션 탭 닫기는 전체 시세 확인 도중에도 언제든 눌러서 정리할 수 있어.

4 결론

등급 기준(13주 누적): 브론즈 15만 · 실버 30만 · 골드 60만 · 다이아 90만 · 레드 150만 · 블랙 300만
자료: 나무위키 메이플/MVP · 넥슨 공식 가이드 · 시세 출처 로아땡(itemthankyou.com)
