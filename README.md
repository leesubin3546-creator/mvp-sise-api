# mvp-sise-api

메이플 MVP작(엠작) 비용 계산기 + 시세 자동수집 백엔드. Render 무료티어 배포용.

- `mvp_calculator.html` — 계산기 프론트엔드(단일 파일). `/` 접속 시 이 화면이 뜸.
- `listings.html` — 매물 찾기 화면. `/listings` 접속 시 이 화면이 뜸.
- `server.js` — 메소마켓 시세(`/api/sise`) + 옥션 시세 릴레이(`/api/auction-price`) +
  매물 목록 릴레이(`/api/auction-listings`) API.
- `userscript/auction-price-reporter.user.js` — 옥션 페이지에서 가격과 매물 목록을 읽어 백엔드로
  보고하는 유저스크립트.

## 매물 찾기 (`/listings`)

옥션의 검색 필터를 그대로 재현해서, 조건에 맞는 매물을 목록으로 보여줌. 아이템명/분류/가격/스타포스/
잠재·에디 등급에 더해 **잠재능력·에디셔널 옵션을 여러 줄** 걸 수 있음(여러 줄 = 모두 만족하는 매물만).

필터는 옥션이 실제로 쓰는 URL 형식 그대로 만들어 보냄:

```
/buy?searchTab=condition&isExactMatch=false&page=1&limit=20
    &sortType=PRICE_PER_ITEM_ASC&itemCategory=ARMOR
    &enhancementOption::starforceMin=17
    &enhancementOption::potentialGrade=legendary
    &enhancementOption::potentialFilters::optionRows=strPercent%1F13%1EphysicalAttackPercent%1F12
```

- 옵션 한 줄은 `코드` + `%1F`(U+001F) + `최소값`, 줄과 줄 사이는 `%1E`(U+001E)로 이어붙임.
- **월드 범위는 이름과 뜻이 반대인 파라미터**라 주의: `isAllWorldSearchEnabled=true`가 오히려
  **현재 월드만**(옥션의 "현재 월드 아이템만" 체크 = 검색 API의 `myWorldOnly:true`)이고, 파라미터를
  빼는 게 전체 월드임. 이름만 보고 반대로 넣으면 옥션이 조용히 전체 월드를 돌려줌. 전체 월드로 검색하면
  타 월드 매물이 섞여 나오는데(구매 시 월드 이전 수수료가 붙음), 매물 표에 `타 월드` 칩으로 표시함.
- `enhancementOption::` 키의 콜론은 인코딩하면 안 먹어서, 키는 그대로 두고 값만 인코딩함.
- 옵션 코드는 추측하지 말 것. 옥션 필터 패널 콤보박스의 React props 에서 그대로 읽어옴:
  잠재능력/에디셔널 39종(`POT_OPTIONS`), 추가 옵션 12종(`EX_OPTIONS`, `ex*`),
  주문서 강화 8종(`SCROLL_OPTIONS`).

### 파라미터 실측 결과 (2026-10-26)

옥션은 모르는 파라미터를 **조용히 무시**해서, 틀려도 화면상 아무 일도 안 일어남. 그래서 전부 결과로 확인함.

| 파라미터 | 결과 |
|---|---|
| `price::min` / `price::max` | ✅ |
| `basicOption::jobClass` | ✅ |
| `basicOption::levelMin` / `levelMax` | ✅ 단, **아이템 기본 레벨 기준**. 환생의 불꽃으로 착용 레벨이 내려간 매물은 툴팁에 175로 보여도 기본 200이라 레벨 200 필터에 잡힘 |
| `enhancementOption::starforceMin` / `Max` | ✅ |
| `enhancementOption::remainUpgradeCountMin` | ✅ |
| `enhancementOption::additionalOption::optionRows` | ✅ **합산 기준** — "INT,LUK +36" 과 "INT +66" 이 더해져 102 로 잡힘 |
| `enhancementOption::scrollUpgrade::optionRows` | ✅ (단 코드가 `total*` 이 아니라 `str`/`int`/`maxHP`/`PAD` 꼴) |
| `enhancementOption::potentialFilters::isAddAll` | ✅ `true` 6,311건 / `false` 0건 (한 줄에 INT 18% 는 없으므로 정상) |
| `isAllWorldSearchEnabled` | ✅ 이름과 뜻이 반대 (위 참고) |

**조건이 너무 넓으면 0건이 나옴.** 분류만 걸고 검색하거나 레벨 1~300 같은 사실상 무조건을 걸면
결과가 0으로 돌아옴 — 필터가 고장난 게 아니라 옥션이 그렇게 응답함. 뭔가 0건이면 조건을 *좁혀서* 가 아니라
*조금 더 구체적으로* 바꿔서 확인할 것.

### 매물 상세 옵션은 어떻게 가져오나

옥션 목록 화면은 스타포스·잠재·추가 옵션을 글자로 안 보여줌(마우스 오버 툴팁에만 나옴). 대신 **그 툴팁을
그리는 데이터가 검색 결과와 함께 이미 내려와 있음** — 유저스크립트가 매물 행의 React 컴포넌트 props에서
`item.toolTip.upgradeInfo`를 읽어 옥션에 추가 요청 없이 그대로 가져옴:

- `starForce` — 현재/최대 성수
- `scroll` — 주문서 강화 사용/잔여/복구 가능 횟수
- `potential`, `additionalPotential` — 등급 + 옵션 줄 전체
- `exOption` — 추가 옵션 줄 전체

매물 찾기 표에서 **행을 누르면** 이 네 가지가 펼쳐짐. props 구조가 바뀌면 예전처럼 화면 텍스트를 긁는
방식으로 자동 폴백하는데, 그때는 상세 옵션 없이 이름·가격·등급만 나옴.

검색 조건은 브라우저 `localStorage`에 저장됨(마지막 조건 자동 복원 + 이름 붙여 저장하는 프리셋).

### 시세 통계 (검색 1회로 전체 분포)

**페이지 넘기기는 하루 100회 검색 제한을 소모하지 않음.** `buySearchKey`를 들고 그대로 `page=N`으로
이동하면 같은 검색으로 취급됨 — 1회 검색 뒤 5페이지·90페이지(마지막)까지 가도 `검색 횟수 1/100`
그대로인 걸 확인함.

이걸 이용해서, 유저스크립트가 **분위수 자리의 페이지만 콕 집어** 훑고 온다. 결과가 `개당 낮은 가격순`
으로 정렬돼 있으면 "n번째로 싼 매물"의 자리가 곧 분위수라서, 중앙값·사분위가 추정이 아니라 **전체
건수 기준 정확한 순위값**이 됨. 정렬이 다르면 가져온 표본 안에서만 계산하고 그렇게 표시함.

1페이지만 보면 안 되는 이유(에테르넬 나이트헬름 1,785건 실측):

| | 개당 가격 |
|---|---|
| 1페이지 | 1,499만 |
| 5페이지 | 2,000만 |
| 90페이지(마지막) | 5,500억 |

매물마다 **중앙값 대비 몇 %** 인지도 같이 표시되고, 옥션 헤더의 `검색 횟수 n/100`을 유저스크립트가
함께 보고해서 남은 하루 예산도 화면에 뜸.

### 매물 표 읽는 법

칼럼은 `아이템 / 개당 가격 / 시세 대비 / ★ / 남은 시간` 다섯 개. **개당 가격**이 기준이고 묶음 매물만
총액을 작게 덧붙임 — 묶음과 낱개를 같은 줄에서 비교하려면 개당이어야 함.

잠재·에디 옵션은 매물을 고르는 핵심이라 **접지 않은 상태에서도 한 줄 요약**으로 보여줌. 원문 그대로
쓰면 "보스 몬스터 공격 시 데미지 +40%" 한 줄이 화면을 다 먹어서 `보공 40% · INT 12%` 처럼 줄임
(`OPT_SHORT` 표). 표에 없는 새 문구는 그대로 둠. 행을 누르면 원문과 추가 옵션·주문서 강화가 펼쳐짐.

`개당 가격` `★` `남은 시간` 헤더를 누르면 정렬(오름차순 → 내림차순 → 해제). 값이 없는 매물은 항상
아래로 내림. 하위 25% 이하 가격인 매물은 행 왼쪽에 초록 선이 붙음.

### 옥션 탭을 한 번 띄워놓고 주소를 넣는 이유

새로 연 탭에 곧바로 검색 URL을 넣으면 옥션이 가끔 파라미터를 통째로 버리고 "검색결과가
초기화되었습니다"만 띄움(앱이 뜨기 전에 주소가 들어가서인 듯). 같은 탭에 두 번째로 넣으면 정상이라,
빈 `/buy` 로 탭을 먼저 열고 2.5초 뒤에 검색 주소를 넣음.

### "옥션엔 있는데 여기선 0건" 이 나올 때

조건이 자동 복원되는 게 편한 대신, 예전에 걸어둔 조건이 그대로 따라붙어서 **분명히 있는 아이템이 0건으로
나오는** 문제가 있었음. 실제 사례: `에테르넬 나이트헬름`(전사 투구)을 검색했는데 이전에 써둔
`직업군 = 마법사`가 남아 있어서, 키워드만으로는 1,328건이 나오는 검색이 0건이 됐음.

그래서 검색 버튼 위에 **지금 걸린 조건**을 칩으로 항상 깔아두고(결과를 좁히는 조건은 주황색), 칩의 ✕로
하나씩 빼거나 **↺ 조건 전체 초기화**(아이템명만 남김)로 한 번에 지울 수 있게 함. 결과가 0건이면 그
조건들을 다시 보여주면서 "이것들이 걸러낸 것"이라고 알려줌.

## 아이템 표 저장

경매장식 아이템 표(이름/캐시가/판매가)는 브라우저의 `localStorage`에 저장됨 — 새로고침하거나
서버가 재시작(무료티어 슬립 등)돼도 마지막 상태 그대로 남아있음. 서버 메모리를 안 쓰기 때문에 브라우저별로
따로 저장되고(다른 PC·다른 브라우저에서는 공유 안 됨), **↺ 기본값으로 초기화** 버튼으로 언제든
2026-10-22 캐시샵 공지 기준 프리셋으로 되돌릴 수 있음.

## 경매장식 "🔍 시세" 버튼

계산기의 아이템 표에서 각 행의 🔍 버튼을 누르면:

1. 그 아이템 이름으로 메이플 옥션 **구매**(개당 실시간 최저가, `PRICE_PER_ITEM_ASC`, `isExactMatch=true`) 검색
   결과만 조회함. 정확히 일치 검색이 필수인 이유: false로 하면 "프리미엄 성형 쿠폰"을 검색할 때 "상반기 BEST
   프리미엄 성형 쿠폰" 같은 별개 아이템까지 같이 잡혀서 서로 다른 아이템끼리 가격이 뒤섞임.
   최근 거래 시세(`/price`, `TRADE_DATE_DESC`)는 안 봄 — 최저가만으로 충분하다고 판단해 뺐고, 덕분에
   탭도 **1개만** 계속 재사용하면 됨(전에는 탭 2개를 같이 열었는데, 같은 넥슨 계정 세션으로 탭 2개가
   동시에 열려 있으면 옥션이 "다른 환경에서 접속이 감지되어 세션이 종료되었습니다"로 세션을 강제
   종료시키는 문제가 있었음). 아이템 표 위의 **🗙 옥션 탭 닫기**는 전체 시세 확인 도중에도 언제든 눌러서
   탭을 정리할 수 있고, 계산기 탭을 닫을 때도 자동으로 닫힘.
2. 탭에서 검색어를 바꾼 직후에는 옥션 페이지가 검색을 마칠 때까지 몇 초(기본 5초) 기다렸다가
   `/api/auction-price` 폴링을 시작함 — 너무 빨리 읽으면 아직 결과가 안 뜬 상태라 못 찾은 것으로 처리됨.
3. 유저스크립트가 설치돼 있으면, 그 탭에서 화면의 **맨 위(=최저가)** 개당 가격을 읽어 자동으로
   백엔드에 보고 → 계산기가 그 값을 판매가 칸에 채워 넣음.
4. **열린 옥션 탭에서 로그인이 안 돼 있으면** 유저스크립트가 설치돼 있어도 검색 결과 자체가 안 떠서
   읽을 값이 없음 — 이 경우 계산기는 "Tampermonkey 미설치"와 "로그인 안 됨"을 구분할 수 없으므로 안내
   메시지에 둘 다 확인하라고 표시함. 설치 안내 새 탭은 계산기를 새로고침한 뒤 세션당 한 번만 자동으로 뜸.

### 왜 서버가 직접 옥션 시세를 못 가져오나

메이플 옥션 웹 버전은 넥슨 OTP 인증 + 로그인된 (레벨 200 이상, 최근 접속 이력 있는) 캐릭터 세션이 있어야만
접근 가능함. 서버가 사용자 대신 로그인하려면 계정 자격 증명이나 세션을 저장해야 하는데, 이는 계정 자동화로
간주될 수 있어 하지 않음. 대신 **사용자 본인이 이미 로그인한 브라우저 화면**에서 유저스크립트가 화면에
보이는 숫자만 읽어 보고하는 방식으로 우회함 — 로그인을 대신하거나 자격 증명을 다루지 않음.

### 유저스크립트 설치

1. Chrome/Edge 등에 [Tampermonkey](https://www.tampermonkey.net/) 확장 설치
2. Tampermonkey 대시보드 → "새 스크립트" → `userscript/auction-price-reporter.user.js` 내용 붙여넣기
   (또는 GitHub raw 링크로 바로 설치)
3. 백엔드 주소를 바꿔서 배포했다면 스크립트 상단 `BACKEND` 상수만 수정

설치 안 해도 🔍 버튼은 옥션 탭을 열어주니 눈으로 보고 판매가 칸에 직접 입력하면 됨 — 유저스크립트는
그 입력을 자동화해줄 뿐.

## Render 배포

1. 이 저장소를 GitHub에 올리고 Render → New → Web Service로 연결
2. Build: `npm install` / Start: `npm start` / Instance: Free
3. Settings → Build & Deploy → **Auto-Deploy: On** 권장 (꺼져 있으면 push 후 수동으로 Manual Deploy 필요)

### 의존성 버전 고정

`package-lock.json`을 커밋함. 예전엔 `.gitignore`에 있어서 Render가 배포할 때마다 의존성을 새로
풀었는데, 그러면 코드를 안 건드려도 상위 패키지 패치에 따라 배포 결과가 달라짐(실제로 어느 배포에서는
express 4.22.2가 잡혀서 `npm audit`이 취약점 4건을 띄웠고, 다음 배포에선 4.22.3이 잡혔음).

대신 **보안 패치가 저절로 따라오지 않으니** 가끔 `npm audit` 보고 필요하면 이렇게 올려줘야 함:

```
npm audit fix && npm install
```

### 추가 옵션 환산 / 가위 · 교환 조건

**추옵 환산**: 추가 옵션은 수치가 제각각이라 그대로는 매물끼리 비교가 안 돼서 하나로 모아 점수를 냄.
유저스크립트가 글로 된 줄만이 아니라 옥션 원본 수치(`toolTip.exOptionStat`)를 `exStat` 으로 같이
보내주기 때문에 글자 파싱이 아님. 가중치는 직업·세팅마다 달라서 못 박지 않고 입력으로 뺐고
(기본값은 흔히 쓰는 **공격력 1 = 주스탯 4**), 브라우저에 저장됨. 주스탯을 INT 로 두면 공격력 대신
마력을 봄. `추옵` 칼럼을 눌러 정렬할 수 있음.

**가위 / 교환 조건**: 별도 숫자 필드가 없고 `toolTip.tradeDesc` 안에 글로 들어있음.

```json
["1회 교환 가능 (거래 후 교환 불가)", "(가위 사용 잔여 횟수 : 8 / 10)"]
```

여기서 잔여/최대를 뽑아 `cut`, 교환 조건 줄을 `tradeNote` 로 보냄. 가위를 이미 쓴 매물(잔여 < 최대)은
되팔 때 불리해서 목록에 칩으로 표시하고, 상세에는 교환 조건과 함께 보여줌.

**기타 조건 필터** (가위 잔여 횟수 / 가위 미부여 / 장착 시 교환 불가 / 추옵·잠재 추출 가능)도 검색
조건에 들어있음. 여기엔 함정이 둘 있어서 실측으로 확인하고 넣었음:

- 개별 불린 파라미터가 **아님.** 켜진 것들의 이름을 쉼표로 이어 붙인 목록 하나로 나감:
  `etcOption::activeOptions=uncuttable,isBindedWhenEquipped,isExPassDown,isPotentialPassDown`
  (요청 본문에서는 `isExOptExtractable` / `isPotentialExtractable` 로 이름이 또 바뀜)
- 가위 범위는 `cuttableCountMin/Max` 만 보내면 **무시됨.** `activeOptions` 에 `cuttableCount` 가
  같이 들어가야 적용됨.
- 옥션 UI 라벨은 "가위 사용 횟수"지만 실제로는 **잔여 횟수** 기준임. 10~10 으로 걸면 잔여 10/10 매물만
  499건 나옴(사용 횟수였다면 가위를 10번 쓴 매물이라 거의 없어야 함).
- `uncuttable`(가위 사용 횟수 미부여)은 **거래 제한이 걸린 장비 중** 가위 횟수가 붙지 않은 것을 고름.
  방어구 ★22 기준 8,290건 → 1,024건이고 전부 가위 줄 없이 "1회 교환 가능"만 달려 있음.
  **자유 거래 아이템에는 적용되지 않음** — 프리미엄 헤어 쿠폰처럼 `tradeDesc` 가 아예 빈 매물은
  89건이 멀쩡히 있는데도 이 조건을 켜면 0건이 됨(가위 개념 자체가 없는 아이템이라 대상 밖).

### 저장된 조건 일괄 조회

저장해둔 조건 여러 개를 한 번에 돌려서 **시세만 먼저 비교**하는 화면. 조건마다 전체 매물 수·최저가·
중앙값·최저가 매물이 한 줄로 뜨고, 줄을 누르면 그 조건의 매물 전체가 아래 표에 펼쳐지면서 검색 조건도
같이 복원됨.

검색 횟수를 조건 수만큼 쓰기 때문에:

- 실행 전에 **몇 회 쓸지** 보여주고, 남은 하루 예산보다 많으면 아예 시작하지 않음
- 옥션의 **5초 연속검색 제한** 때문에 조건 사이를 6초 띄움
- 탭은 여전히 **1개만** 재사용함 (동시에 2개 열리면 넥슨이 세션을 끊음)

### 메이플크레딧 환산 (참고 블록)

마일리지가 사라진 자리에 들어온 건 **메이플크레딧**(넥슨캐시 결제액의 5%)인데, 캐시샵 할인에는 못 쓰고
크레딧샵 전용이라 **비용 계산 본문에는 넣지 않음.** 대신 결론 앞 접힘 블록에서 "덤이 얼마짜리인지"만
따로 환산함.

- 적립 기준은 **소모한 넥슨캐시(=실적)** 이지 충전 할인 뒤 낸 원화가 아님
- 크레딧샵 물건(프라임 큐브 10,000 / 솔 에르다 9,900)은 선물은 안 되지만 **사용 전 1회 거래**가 되므로
  경매장 시세로 메소·현금 환산이 가능함
- 10캐시 미만 아이템과 선물하기는 적립 대상이 아님
